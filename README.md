## 🎯 Sobre el Curso

Este curso está diseñado para proporcionar una formación completa en FreeCAD, desde los conceptos básicos hasta técnicas avanzadas de modelado 3D paramétrico. El material está en constante desarrollo y actualización para reflejar las últimas características y mejores prácticas.

## 🔧 ¿Qué es FreeCAD?

FreeCAD es un modelador 3D paramétrico de código abierto, diseñado principalmente para diseñar objetos de la vida real de cualquier tamaño. El modelado paramétrico permite modificar fácilmente el diseño volviendo al historial del modelo y cambiando sus parámetros.

**Características principales:**
- 🆓 Software libre y de código abierto (LGPL License)
- 🌐 Multiplataforma (Windows, Mac, Linux)
- 📐 Modelado paramétrico
- 🏗️ Arquitectura modular con diversos workbenches
- 🐍 Scriptable con Python
- 📊 Importación/Exportación de múltiples formatos (STEP, IGES, STL, SVG, DXF, OBJ, etc.)

## 🎓 Objetivos del Curso

Al completar este curso, serás capaz de:

- ✅ Comprender los conceptos fundamentales del diseño paramétrico
- ✅ Navegar eficientemente por la interfaz de FreeCAD
- ✅ Utilizar los principales workbenches (Part, Part Design, Sketcher, etc.)
- ✅ Crear modelos 3D complejos utilizando técnicas de modelado avanzadas
- ✅ Generar planos técnicos y documentación de proyectos
- ✅ Preparar modelos para impresión 3D
- ✅ Aplicar FreeCAD en proyectos reales de diseño e ingeniería

## 💻 Instalación de FreeCAD

### Windows
1. Descarga el instalador desde [freecad.org](https://www.freecad.org/downloads.php)
2. Ejecuta el archivo `.exe` y sigue las instrucciones del asistente

### macOS
1. Descarga el archivo `.dmg` desde [freecad.org](https://www.freecad.org/downloads.php)
2. Arrastra FreeCAD a la carpeta Aplicaciones

### Linux
```bash
# Ubuntu/Debian
sudo apt-get update
sudo apt-get install freecad

# Fedora
sudo dnf install freecad

# Arch Linux
sudo pacman -S freecad
```

También puedes usar el AppImage disponible en la página oficial.

## 📖 Estructura del Curso

> **Nota:** El contenido del curso está en desarrollo activo. La estructura se actualizará a medida que se añadan nuevos materiales.

El curso se organizará en módulos progresivos:

1. **Introducción a FreeCAD**
   - Interfaz y navegación
   - Configuración inicial
   - Conceptos básicos

2. **Sketcher - Dibujo 2D**
   - Herramientas de dibujo
   - Restricciones
   - Dimensionamiento

3. **Part Design - Modelado 3D**
   - Operaciones básicas (Pad, Pocket, etc.)
   - Modificadores
   - Patrones y arrays

4. **Part - Operaciones booleanas**
   - Unión, resta, intersección
   - Trabajo con sólidos

5. **Draft - Dibujo técnico**
   - Herramientas de dibujo 2D
   - Acotación
   - Anotaciones

6. **TechDraw - Planos técnicos**
   - Creación de vistas
   - Dimensionamiento
   - Plantillas personalizadas

7. **Proyectos Prácticos**
   - Ejercicios guiados
   - Proyectos completos
   - Casos de estudio
